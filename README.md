# Base Token Creator

Create and deploy your own ERC-20 token on **Base Network** directly from your browser.

🌐 **Live App:** https://www.dremart.com/web3/base-token-creator/

## About

Base Token Creator is a Web3 application designed to make ERC-20 token creation on Base simple and accessible.

Users can connect a compatible Web3 wallet, configure their token details, and deploy a custom ERC-20 token directly to the Base blockchain.

## Features

- Create ERC-20 tokens on Base Network
- Connect a Web3 wallet
- Set custom token name
- Set token symbol
- Configure total token supply
- Deploy tokens directly on-chain
- Simple and responsive user interface
- Blockchain transaction handling
- View deployed contracts on Base block explorers
- Non-custodial wallet interaction

## How It Works

1. Open the Base Token Creator.
2. Connect your Web3 wallet.
3. Enter your token name.
4. Enter your token symbol.
5. Choose the total supply.
6. Review the token information.
7. Confirm the deployment transaction in your wallet.
8. Your ERC-20 token is deployed on Base Network.

## Security

The application uses non-custodial wallet interaction. Blockchain transactions must be reviewed and approved by the user through their connected wallet.

Never share your private key or wallet recovery phrase with any website or application.
